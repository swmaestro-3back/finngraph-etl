# Companies Pipeline

기업(법인) 마스터와 재무, 이름 사전, 기업 설명을 수집합니다. 종목(`stocks`)이 아니라
**법인** 축입니다.

## Required Data

- 국내 상장·비상장, 외국 기업을 모두 담는 법인 마스터
- 뉴스에 나온 표기를 법인으로 잇는 이름 사전 (`company_aliases`)
- 재무 — 연결(CFS)과 별도(OFS), 분기·연간
- 모든 기업의 설명

## Source Decision

| 대상 | 원천 | 주기 |
| --- | --- | --- |
| 국내 상장 법인 마스터 | KIS master → `stocks` → `companies` | 평일 |
| 국내 상장 재무·ROE·EPS·BPS | KIS 재무 API (연결만) | 평일 배치 |
| 국내 비상장 개요·재무, 상장사 별도(OFS) | OpenDART | 매일 |
| 국내 기업 설명 | DART 사업보고서 → Bedrock 요약, 실패 시 KRX 업종·주요제품 | 매일(회차당 상한) |
| 외국 기업 식별 | KIS 해외 마스터 + 위키데이터 | 주 1회 |

국내 상장 재무의 원천이 DART가 아니라 KIS인 이유는 소급 길이입니다. 삼성전자 기준 연간
23개(2004~)·분기 30개를 주는데 DART 공시 API로는 2015년 이후만 닿습니다. 재무비율에
ROE·EPS·BPS가 분기별로 들어 있어 직접 계산할 필요도 없습니다.

## Implementation

- **자연키가 없어 surrogate id를 씁니다.** 비상장은 ticker가 없고, 외국은 식별자 체계가
  다르며, 한 법인이 여러 시장에 상장됩니다(소니 = 도쿄 6758 + 뉴욕 SONY ADR).
- **금액 단위는 전부 원(KRW)입니다.** KIS 재무는 억원으로 오므로 적재 전에 변환합니다.
  단위가 섞이면 두 원천을 한 화면에서 비교할 수 없습니다.
- **손익은 누적 기준으로 통일합니다.** KIS 분기 행이 누적이고 DART의 당기 누계도
  누적입니다. 분기 단독 값은 파생 단계에서 차분으로 만듭니다.
- **KIS 재무의 `99.99`는 sentinel입니다.** 실제 값이 아니므로 NULL로 바꿔 적재합니다.
- **재무는 append-only입니다.** 정정공시가 새 `rcept_no`로 오므로 덮어쓰지 않고 새 행을
  넣습니다. 공시일(`disclosed_at`)은 `rcept_no` 앞 8자리에서 얻습니다 — KIS는 공시 시점을
  주지 않아 point-in-time이 필요한 분석에는 DART 재무를 써야 합니다.

### 이름 매칭의 함정

- **`company_aliases.alias`에 전역 UNIQUE를 걸면 안 됩니다.** 동음이의어가 실재합니다
  (대덕 → 자치구, 카프로 → 화합물, 성우 → 일본인 성우). 해소는 조회 시점의 문맥으로 합니다.
- **DART 상장사는 `stock_code`로 매칭합니다.** 법인명으로 하면 동명이 걸립니다 — `카카오`는
  정규화 후 정확 매칭을 해도 2건이 나옵니다. 비상장은 법인명 정규화 후 정확 매칭하되,
  2건 이상이면 **보류하고 로그만 남깁니다.** 재무가 엉뚱한 법인에 붙으면 조용히 틀린 값이
  서비스에 나갑니다.
- **부분 문자열 매칭 금지.** `컬리` → `컬리넌종합건설`, `당근` → `당근페이`,
  `소니` → `소니다 시니어 리빙`에 걸립니다.
- **위키데이터는 `P31`(instance of) 기업 타입 필터가 필수입니다.** 없으면 Stripe가
  '줄무늬'로 매칭됩니다.
- 미매칭 표기는 `unresolved_entities`에 빈도로 쌓입니다. 사전을 미리 완벽하게 만들 수는
  없으므로, 빈도순으로 보강하는 루프가 전제입니다.

### 수집 범위를 좁히는 곳

전량 적재와 선별 수집을 나눕니다.

- **비상장**: `corpCode.xml`은 파일 하나라 11만여 건을 전량 적재하되, 개요·재무는 법인당
  API 여러 회라 `service_companies`에 담긴 법인만 수집합니다. 목록이 법인 단위여서
  비상장도 넣을 수 있고, 그 법인은 종목이 없어 시세는 자연히 빠지고 DART 정보만 채워집니다.
- **상장**: 개요·재무도 `service_companies`로 좁힙니다. 상장사 전량(2,581)이면 DART 개요
  13주·재무 26주가 걸려, 1차 MVP 범위(반도체·2차전지 361법인)만 매일 채웁니다.

해외 상장 기업은 수집하지 않습니다. 서비스 범위가 국내라 시세·재무를 제공하지 않고,
뉴스에 나오는 해외 기업은 RDB 법인 행 없이 **그래프 노드로만** 다룹니다.

### 기업 설명

국내 상장사에 위키데이터를 쓰지 않는 이유는 커버리지입니다. 시가총액 2000위권의 한국어
설명 보유율이 0%이고, 있어도 "company in Seoul, South Korea" 수준입니다. 국내는 DART
사업보고서의 "주요 사업의 내용"을 LLM으로 1~2문장 요약하고, 실패하면 KRX 업종·주요제품으로
폴백합니다. `description_source`로 어느 경로였는지 구분합니다.
